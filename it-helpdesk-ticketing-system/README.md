# IT Helpdesk Ticketing System

## Overview

A hands-on IT Support project using osTicket to simulate a helpdesk
environment and understand how IT support teams manage user requests,
assign tickets, track issue status, and handle ticket resolution.

The system was deployed in a local development environment using Laragon.

## Objectives

- Understand the basic workflow of an IT helpdesk ticketing system.
- Practice creating and categorizing support tickets.
- Simulate ticket assignment and troubleshooting.
- Practice documenting technical issues and resolutions.
- Understand basic SLA and ticket status management.

        ↓
Internal note
        ↓

        ↓
Resolution
